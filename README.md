# Jose Pablo Ramírez

I'm an AI engineer from San José, Costa Rica. Right now I build LLM agents for construction estimating at QuoteGoat, and I do research on AI for software engineering at the Universidad de Costa Rica.

Before that I was a software engineer at Microsoft, first on Azure Cosmos DB and then on Xbox Multiplayer Services (PlayFab). Earlier I worked at Kyndryl | IBM.

## What I share

- [strands-acp-client](https://github.com/pablodevrzmz/strands-acp-client): use coding agents like Claude Code, Codex, OpenCode or Qwen Code as tools from a Strands agent, over the Agent Client Protocol. Your agent delegates a task and gets the result back. It's on [PyPI](https://pypi.org/project/strands-acp-client/).
- [ai-engineering-use-cases](https://github.com/pablodevrzmz/ai-engineering-use-cases): small, complete projects on Amazon Bedrock AgentCore and Strands Agents that back what I write on [LinkedIn](https://www.linkedin.com/in/jose-ramirez-mendez/). Each one deploys with Terraform, has a smoke test and tears down with one command.
